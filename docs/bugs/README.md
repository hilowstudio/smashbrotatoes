# Active Bugs

This directory is an **active bug log** — only bugs with genuine remaining work
live here. When you fix one, delete its file and drop it from the table below.
When you find a *new* bug, add a `<slug>_<YYYY-MM-DD>.md` file (symptom → root
cause → fix/plan) and a row here. Historical write-ups are recoverable from git.
